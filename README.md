# College Student–Teacher Management System

A beginner-friendly Spring Boot REST API project for practising the 20-mark CRUD assessment.

## Stack
- Java 17
- Spring Boot 3.4.5
- Spring Web
- Spring Data JPA
- MySQL
- Maven
- Postman

## 1. Configure MySQL
1. Copy the example configuration to create your local `application.properties`:
   ```bash
   cp src/main/resources/application.properties.example src/main/resources/application.properties
   ```
2. Open `src/main/resources/application.properties` and replace `YOUR_MYSQL_PASSWORD` with your actual MySQL password.
3. The database `college_db` is created automatically when the MySQL user has permission.

## 2. Run
From this folder:
```bash
mvn spring-boot:run
```
The API runs at `http://localhost:8080`.

## 3. Main API routes

### Students
| Method | URL | Purpose |
|---|---|---|
| POST | `/students` | Create student |
| GET | `/students` | Get all students |
| GET | `/students/101` | Get student by ID (use actual generated ID) |
| GET | `/students/branch/CSE` | Get students by branch using @PathVariable |\n| GET | `/students/search?branch=CSE` | Get students by branch using @RequestParam |
| PUT | `/students/101` | Update student |
| DELETE | `/students/101` | Delete student |

### Teachers
| Method | URL | Purpose |
|---|---|---|
| POST | `/teachers` | Create teacher |
| GET | `/teachers` | Get all teachers |
| GET | `/teachers/1` | Get teacher by ID |
| GET | `/teachers/department/CSE` | Get teachers by department |
| PUT | `/teachers/1` | Update teacher |
| DELETE | `/teachers/1` | Delete teacher |

## 4. Sample Postman requests

Create a teacher first:
- Method: POST
- URL: `http://localhost:8080/teachers`
- Body → raw → JSON:
```json
{
  "name": "Sharma",
  "department": "CSE",
  "email": "sharma@college.edu"
}
```

Create a student and assign teacher ID 1:
- Method: POST
- URL: `http://localhost:8080/students`
- Body → raw → JSON:
```json
{
  "name": "Ravi",
  "branch": "CSE",
  "email": "ravi@college.edu",
  "teacher": {
    "id": 1
  }
}
```
Use the actual teacher ID returned by your create-teacher request.

Get all students:
- Method: GET
- URL: `http://localhost:8080/students`

Get CSE students:
- Method: GET
- URL: `http://localhost:8080/students/branch/CSE`

Update a student:
- Method: PUT
- URL: `http://localhost:8080/students/1`
- Body:
```json
{
  "name": "Ravi Kumar",
  "branch": "CSE",
  "email": "ravi.kumar@college.edu",
  "teacher": { "id": 1 }
}
```

Delete a student:
- Method: DELETE
- URL: `http://localhost:8080/students/1`

## 5. How this maps to the assessment
- Q1: `StudentController` and `TeacherController` use `@RestController`.
- Q2: `@PathVariable` is used for IDs/branch in URL; `@RequestBody` is used for JSON. `@RequestParam` is explained in the written answer but is not used by these routes.
- Q3: GET, POST, PUT and DELETE implement read, create, update and delete.
- Q4: Service classes contain application logic; Repository interfaces access MySQL through JPA.
- Q5: Follow `GET /students/1` through Controller → Service → Repository → MySQL → JSON response.
- Q6: Create route is `POST /students`; read-by-ID method is `getStudentById`; repository uses `findAll()` for all records; missing IDs produce 404.
- Q7: Use `@PathVariable`, not `@RequestBody`, for an ID in `/students/{id}`.
- Q8: `GET /students/branch/CSE`; service calls `findByBranchIgnoreCase`.
- Q9: Jackson converts JSON from `@RequestBody` into a `Student`; service calls repository `save()`.

## Important learning notes
- IDs are generated by MySQL; do not assume the first ID is always 101.
- The sample code uses a one-way `@ManyToOne` relationship: many students may refer to one teacher.
- Deleting a teacher who is still assigned to students may be rejected by the database. Reassign or delete those students first.
- `spring.jpa.hibernate.ddl-auto=update` is convenient for practice. For production, use controlled database migrations instead.
